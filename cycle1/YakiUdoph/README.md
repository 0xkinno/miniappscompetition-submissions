## Description

Vellum is a mobile-first historical timeline mini app built for crypto users to explore milestones and handle dual USDT and NIM transactions through Nimiq Pay.

## Builder story

History textbooks always felt like reading someone else's old diary from behind a glass wall, distant and dry. I wanted to change that.

I built Vellum to drop you right into the timeline using a second-person perspective, so you aren't just looking at the past; you're experiencing it. Paired with lightweight Nimiq Pay micro-transactions and daily streaks, it turns learning history into a daily ritual that actually sticks.
